Read it. Prove it. Run it.

Two books and a playground for Verse.

openverse is an independent implementation of a deterministic subset of Verse, the functional logic language from Epic Games. Its semantics is defined and proved in Lean 4, and a C runtime is checked against it. Learn the language from the books, then try it in your browser.

In your browser

The playground

Write a Verse program and run it. The openverse compiler and runtime are compiled to WebAssembly and run in a service worker on your own machine: your program is never sent to a server.

The Little Verser

A friendly dialogue about Verse

The same language taught as questions and answers, in the manner of the classic little books: values, names, failure, rollback, loops, options and shapes, ending with openverse's proved promises in plain English. No Lean and no mathematics.

For students of mathematics, logic and CS

Verse Logic

Eight Theorems about a Functional Logic Language

One chapter per core Lean theorem of openverse: adequacy, determinism, rollback, <decides> soundness, type safety, substitution, heap effects and acceptance. Each is stated in symbolic logic, read in Lean, proved in outline and shown at work in Verse programs.

Checked every time this site is built

Every program in both books is run by openverse and its output compared with the output printed in the book; every rejected program must be rejected with the message shown; every Lean statement in Verse Logic must match, symbol for symbol, the statement Lean prints for that theorem. If the books and openverse disagree, the site is not published. The playground's own browser tests run the compiler and runtime through real WebAssembly before each deployment.

More about Verse

These books describe the part of Verse that openverse implements. For the language itself, start with Epic Games' own documentation.

  • The Book of Verse Epic Games' in-depth reference to Verse: its philosophy, its core concepts and the whole language. Also published at verselang.github.io/book, from a public repository.
  • Programming with Verse in Unreal Editor for Fortnite Epic's guides and tutorials for writing Verse in UEFN.
  • The Verse Calculus Augustsson, Breitner, Claessen, Jhala, Peyton Jones, Shivers, Steele and Sweeney, The Verse Calculus: A Core Calculus for Deterministic Functional Logic Programming, Proc. ACM Program. Lang. 7 (ICFP 2023).
  • openverse The implementation, its Lean proofs and C runtime; docs/LANGUAGE.md lists the subset of Verse it supports.
